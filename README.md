I'm a Data Science engineering student focused on building intelligent applications at the intersection of **Machine Learning, Generative AI, agentic systems, and MLOps**.

My interests extend beyond model development to the engineering required to make AI systems useful: retrieval pipelines, tool orchestration, model evaluation, experiment tracking, deployment, and observability.

- **Machine Learning:** Predictive modeling, feature engineering, model evaluation, and end-to-end ML pipelines.
- **Generative AI:** RAG architectures, embeddings, semantic retrieval, and LLM-powered applications.
- **Agentic Systems:** Stateful workflows, tool execution, conditional routing, and multi-agent orchestration.
- **MLOps & LLMOps:** Experiment tracking, data versioning, CI/CD, evaluation workflows, and AI system monitoring.
- **Open Source:** Exploring real-world codebases, understanding system architecture, and contributing to collaborative engineering projects.

I'm particularly interested in the engineering principles that make AI applications **reproducible, observable, maintainable, and reliable**.

## Engineering Workflow

I approach AI applications as systems with multiple connected stages, rather than isolated models or prompts.

```text
                    DATA & KNOWLEDGE
                           |
                           v
              Data Processing & Validation
                           |
                           v
                Embeddings / ML Features
                           |
                           v
              Retrieval / Model Inference
                           |
                           v
                Generation / Prediction
                           |
                           v
                Evaluation & Validation
                           |
                           v
                  API / Application
                           |
                           v
                 Deployment & Runtime
                           |
                           v
             Monitoring & Observability
```

Supporting engineering practices:

- **Reproducibility:** Versioning datasets, tracking experiments, and recording model artifacts.
- **Quality assurance:** Testing critical components and validating outputs.
- **Automation:** Using CI/CD workflows to reduce repetitive manual steps.
- **Observability:** Investigating execution traces, latency, token usage, retrieval quality, and model behavior.
